# LyricBar v0.1.11

Preferences customization release.

## Added

- Setting to hide the separate LyricBar settings icon from the GNOME top bar.
- When the settings icon is hidden, clicking the lyric text opens LyricBar preferences.
- Appearance preferences for lyric text:
  - color presets
  - theme default color mode
  - custom HEX color
  - GTK color picker
  - drop shadow toggle
- Appearance settings in copied diagnostics for easier bug reports.

## Changed

- Lyric text color and shadow are now rendered from validated preferences instead of fixed stylesheet values.
- Stroke/outline support is deferred until there is a safe GNOME Shell rendering approach.

## Verification

- `npm run verify`
- Live GNOME Shell desktop check for the hidden settings icon behavior.
- Live GNOME Shell desktop check for custom text color and color picker behavior.
