# LyricBar v0.1.4

## Highlights

- Improves Spotify Web support through browser-aware MPRIS metadata handling.
- Stabilizes noisy browser player snapshots before lyric lookup and display.
- Reduces stuck-first-line behavior for browser playback when position updates continue but metadata churns.
- Adds architecture documentation for future player profiles.

## Compatibility

- GNOME Shell 46-49
- Spotify Desktop remains the primary target.
- Spotify Web is supported through browser MPRIS metadata on a best-effort basis.

## Notes

YouTube Music and Apple Music browser support are not part of this release.
