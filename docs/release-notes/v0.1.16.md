# LyricBar v0.1.16

Control where LyricBar sits inside its panel box.

## Added

- **Panel index** (Preferences -> Display): choose the order of the lyric indicator inside the selected panel box. `0` keeps the current behavior (first item), `1` places it after Activities when the panel position is `Left`, and `-1` appends it to the end of the box. Range `-1..20`; default `0`. Changes apply immediately ([#17](https://github.com/fikrilal/gnome-lyricbar/issues/17)).
- Copy diagnostics now includes the panel index.

## Verification

- `npm run verify` and `npm audit` clean on the release commit.
- Unit tests for panel index normalization, reposition detection, and settings subscription; schema range enforced by `glib-compile-schemas`.
- Live check on GNOME Shell 50.1 (Ubuntu 26.04.1, Wayland): changing the panel index moves the indicator at runtime.

## Notes

- The separate settings icon is unchanged and still mounts at the start of the right box.
