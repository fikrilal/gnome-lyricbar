# LyricBar v0.1.12

Browser player stability release.

## Fixed

- Suppress browser position reads while Chrome is debouncing direct track metadata changes.
- Prevent old synced lyrics from briefly restarting at the new track's near-zero browser position during fast browser transitions.
- Keep playing Chrome browser media selected while paused preferred players, such as Spotify Desktop, are also present.

## Changed

- Consolidated TIDAL Web documentation around the observed Chrome MPRIS route.
- Moved completed TIDAL/browser investigation plans into completed execution-plan docs.
- Removed duplicated historical WIP notes after preserving durable evidence.

## Verification

- `npm run verify`
- Live GNOME Shell 46 desktop check with TIDAL Web playing through Google Chrome.
- Runtime logs confirmed Chrome was selected as the active player, synced lyrics advanced, and paused Spotify did not steal selection.
