# LyricBar v0.1.10

Firefox YouTube Music reliability release.

## Fixed

- Preserve browser media URLs across partial Firefox MPRIS metadata updates.
- Detect YouTube Music Web from Firefox `music.youtube.com` URLs in GNOME Shell runtime without relying on the WHATWG `URL` global.
- Prevent stale browser service preferences, such as Apple Music Web, from overriding strong Firefox YouTube Music URL evidence.
- Keep Firefox YouTube Music synced lyrics moving when Firefox reports `Position=0` for the whole track.

## Changed

- Firefox YouTube Music now holds low-confidence zero-position samples, then estimates lyric position after a short stagnation threshold.
- Real MPRIS positions still take priority whenever Firefox reports usable timing.

## Verification

- `npm run verify`
- Live Firefox YouTube Music desktop check on GNOME Shell 46.
- Runtime logs confirmed `profile="youtube-music-web"`, `sync-position-held-low-confidence`, `sync-position-estimated`, and advancing lyric lines while Firefox reported `Position=0`.
